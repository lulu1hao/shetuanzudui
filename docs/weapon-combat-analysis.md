# 武器伤害与击杀分析

装备卡片的默认模式 DPS、DPS 排序、战术检视和枪械对比共用 `src/utils/weaponCombat.js`。伤害和时序来自已同步的 Wiki 数据；不读取可能落后的 Wiki DPS 字段来充当推算结果，也不直接把旧击杀表作为最新档案。

## 展示与计算口径

- 默认目标为 150 / 250 / 350 HP，按衰减前、当前选定攻击模式全部命中计算。只对有明确爆头伤害的模式提供爆头选项。
- **每次伤害**：一发子弹、一次扳机或一组连击的总伤害。连击表同时展示单颗命中数和攻击组数；霰弹可调命中弹丸数量。
- **输出 DPS**：完整攻击周期的平均输出，计入连发间隔、转管和双弹匣快换，不计整匣换弹。普通枪为 `伤害 × RPM / 60`；连发和多段攻击按本轮伤害除以循环时间。
- **含换弹 DPS**：整匣总伤害除以“第一发命中到下一弹匣第一发命中”的周期。假设末发命中后立即开始换弹，换弹期间不额外重复添加普通射击间隔；燃烧按周期内刷新后的覆盖时间计入。
- **首击后**：第一击命中为 0 秒，逐次排布后续命中及必要换弹，累计伤害达到目标 HP 的时刻。一击击杀为 0 秒，不代表按键到击杀无需时间。
- **含起手**：首击后的时间加首次蓄力、前摇或起转。提前蓄力仅移除首次等待，后续攻击仍使用完整循环；不会把每次蓄力重复加到已经包含它的 RPM 中。
- 忽略弹道飞行、距离衰减、护甲、治疗、移动、瞄准和网络延迟。榴弹的引信也不计入。数值是指定条件下的理论估算，不代表实战胜率。
- Wiki 没有可靠时序时仍计算所需命中数，DPS/时间显示待测；用户可填训练场实测间隔、前摇、连击间隔。自填结果标明“手动时序试算”，切换武器/模式或同步数值变化后清空，防止旧实测悄悄套到新版本。

## 38 把武器的机制映射

| 武器 | 计算方式与模式 |
| --- | --- |
| LH1、M11、SR-84、V9S、XP-54、AKM、CB-01 Repeater、Chimera-XB、FCAR、P90、Pike-556、R .357、BFR Titan、Lewis Gun、M60 | 单发伤害与当前 RPM；身体/爆头分别计算，弹匣不足才插入换弹 |
| .50 Akimbo | 双枪交替，每次按一颗子弹伤害计算，不因双持再乘二 |
| KS-23 | 独头弹，单弹伤害，不当作多弹丸霰弹，也不虚构爆头 |
| M26 Matter、SH1900、Model 1887 | 单弹丸伤害 × 实际命中数量，支持弹匣不足时换弹 |
| FAMAS、93R | 三连发逐颗计算；周期为两次组内间隔 + 末发到下一组首发的等待 |
| ARN-220 | 两个相连弹匣，先快换、后完整换弹，两种停顿分别插入 |
| ShAK-50 | 两颗弹同时命中，伤害与消耗均乘二；20 发弹药只支持 10 次扳机 |
| Recurve Bow | 轻拉/满蓄力分开取伤害与 RPM，满蓄力加入首次蓄力，可切换已拉满 |
| Throwing Knives | 主攻两刀先后命中，组间等待与组内间隔相加；蓄力副攻使用 Wiki 每次投掷总伤害，不重复翻倍 |
| SA1216 | 四发组内射击后转管，16 发耗尽后完整换弹；不能将组内 RPM 直接作为整匣射速 |
| M134 Minigun | 稳定预热/冷启动。冷启动加速曲线不套固定延迟；仅在命中数、稳定射速时间与当前数值匹配时使用对应 Wiki 冷启动实测，否则等待实测参数 |
| CL-40、MGL32 | 直击/内圈溅射/外圈溅射互斥；直击与溅射不会重复相加 |
| Cerberus 12GA | 弹丸命中加单层燃烧，后续命中刷新燃烧时长，允许在两发之间燃烧击杀；可关闭燃烧 |
| Flamethrower | 直接喷射/加持续燃烧；燃烧时长缺失时要求填实测值，默认只显示可确认的直接输出 |
| Dagger | 普通挥刺/蓄力正面/蓄力背刺，背刺须背后命中；第二次背刺使用完整蓄力攻击循环 |
| Sword | 普攻/蓄力突刺，支持边缘命中与提前蓄力 |
| Sledgehammer | 横扫/重砸独立伤害和攻击循环，支持边缘命中 |
| Riot Shield | 警棍/举盾冲撞独立伤害和循环；无爆头。当前 86 伤害打 350 HP 为 5 次，不沿用原表的 4 次 |
| Spear | 普通刺击/三段旋转；旋转三击使用不同伤害和命中时刻，不按最后一段伤害乘三 |
| Dual Blades | 双斩按两次先后命中计算；格挡/反弹说明依赖来弹，无独立固定 DPS |

燃烧采用每秒伤害的连续流近似，非游戏逐 tick 模拟，不逐发/逐弹丸叠加燃烧层数。换弹期间燃烧可继续，到期即停止。近战缺失的攻速和前摇不会从历史补丁或其他近战武器移植。

## 数据来源与更新

`wikiEquipmentParser.js` 解析信息框，`weaponWikiMechanics.js` 解析当前正文和带模式标签的 Damage Profile。先截断 History / Item Mastery / Cosmetics / Trivia 等后续章节，再匹配时序，避免把历史数字当成当前数值。解析器版本变更会触发正文重读。

`src/data/weaponCombatSnapshot.json` 是 2026-09-27 抓取的 38 把武器离线快照，包含修订 ID、来源时间、信息框与当前时序。同步成功后由新数据覆盖。旧缓存只在同修订时借用快照的时序，不把不同版本数值与时序混合。

维护者刷新快照：

```powershell
node scripts/probe-equipment-wiki.mjs
node scripts/build-weapon-combat-snapshot.mjs
```

主要机制来源：[反曲弓](https://www.thefinals.wiki/wiki/Recurve_Bow)、[飞刀](https://www.thefinals.wiki/wiki/Throwing_Knives)、[FAMAS](https://www.thefinals.wiki/wiki/FAMAS)、[SA1216](https://www.thefinals.wiki/wiki/SA1216)、[ARN-220](https://www.thefinals.wiki/wiki/ARN-220)、[ShAK-50](https://www.thefinals.wiki/wiki/ShAK-50)、[加特林](https://www.thefinals.wiki/wiki/M134_Minigun)、[长矛](https://www.thefinals.wiki/wiki/Spear)、[防暴盾](https://www.thefinals.wiki/wiki/Riot_Shield)。原表和信息框可能不同步，因此界面展示当前推算及原表对照，并标出差异。

## 验证

`npm.cmd run test:equipment` 包含同步回归、全部 38 把武器及攻击模式覆盖，以及蓄力只算一次、霰弹乘数、连发/转管、双弹匣、双弹消耗、燃烧、冷启动失效条件、旧缓存升级和无效手动时序用例。`npm.cmd run build` 验证 Vue 组件与页面集成。
